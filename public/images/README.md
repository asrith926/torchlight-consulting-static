# Images Directory

## Required Images:

### `/images/srikanth.jpg`
- **Purpose**: Professional portrait for Hero section
- **Dimensions**: Recommended 400x400px or larger (square aspect ratio)
- **Format**: JPG, PNG, or WebP
- **Requirements**: 
  - Professional headshot/portrait
  - High resolution for retina displays
  - Good lighting and contrast
  - Should work well in a circular crop

To add your portrait:
1. Place your professional portrait image in this directory
2. Name it `srikanth.jpg` (or update the path in `components/Hero.tsx` line 116)
3. Ensure the image is at least 400x400px for best quality

The current website will show a broken image icon until this file is added.
